# File Catalog / 文件目录生成器

读取指定文件的标题，生成带缩进的可点击目录树。支持代码块动态渲染、命令插入、自定义标题层级、快捷键配置与冲突检测。

替代 DataviewJS 的 filecatalog 脚本，无需 Dataview 依赖。

## 功能特性

- **代码块动态渲染**：在笔记里写 ` ```filecatalog ` 代码块，阅读视图自动渲染目标文件的标题目录
- **支持 `[[]]` 链接格式**：代码块里写 `[[文件名]]` 可触发 Obsidian 自动补全，快速选择文件
- **命令插入**：`Ctrl+P` 搜索命令，将目录作为静态 markdown 插入到当前光标位置
- **标题层级自定义**：可选择 H1-H6 哪些层级显示在目录里，默认 H2 + H3
- **快捷键自定义**：在插件设置面板直接为命令配置快捷键，即时检测冲突
- **智能链接**：标题含 `[[]]` 链接则保留原样，否则自动生成 `[[文件名#标题|标题]]` 内部链接

## 安装

### 方式一：手动安装

1. 下载最新 Release 的 `main.js`、`manifest.json`、`styles.css`
2. 在 Obsidian 仓库下创建 `.obsidian/plugins/file-catalog/` 目录
3. 将 3 个文件放入该目录
4. Obsidian → 设置 → 第三方插件 → 关闭安全模式 → 找到「文件目录生成器」→ 开启

## 使用方法

### 代码块动态渲染

在笔记里写：

~~~
```filecatalog
[[test]]
```
~~~

或直接写文件名：

~~~
```filecatalog
test
```
~~~

阅读视图会动态渲染 test 文件的标题目录。推荐用 `[[test]]` 格式，因为输入 `[[` 时 Obsidian 会弹出文件列表供选择。

### 命令插入

| 命令 | 作用 |
|------|------|
| 插入文件目录 | 弹输入框，输入文件名后插入目录 markdown |
| 插入当前文件目录 | 直接插入当前文件的标题目录 |

### 生成的目录格式

```markdown
- [[test#一级标题|一级标题]]
    - [[test#二级标题|二级标题]]
        - [[test#三级标题|三级标题]]
- [[test|已有链接的标题]]  ← 标题本身含 [[]] 链接则保留原样
```

每个标题都是可点击的内部链接，按标题层级自动缩进。

## 设置说明

| 设置项 | 说明 |
|--------|------|
| 显示的标题层级 | 勾选 H1-H6 中要显示的层级，默认 H2 + H3 |
| 快捷键设置 | 为「插入文件目录」和「插入当前文件目录」配置快捷键，即时检测冲突 |

## 替代 Dataview

| | DataviewJS (原) | 本插件 |
|---|---|---|
| 依赖 | 需要 Dataview 插件 | 无依赖 |
| 代码块 | ` ```dataviewjs ` | ` ```filecatalog ` |
| 文件选择 | 手动输入文件名 | 支持 `[[文件名]]` 自动补全 |
| 标题层级 | 全部显示 | 可自定义 H1-H6 |
| 快捷键 | 不支持 | 内置配置 + 冲突检测 |
| 命令插入 | 不支持 | 支持 |

## 技术说明

- 纯 JavaScript 实现（`main.js`），无需编译，直接可用
- `main.ts` 为 TypeScript 源码参考，供二次开发使用
- 使用 `metadataCache.getFileCache` 读取标题元数据
- 使用 `MarkdownRenderer.renderMarkdown` 渲染目录
- 快捷键通过 `hotkeyManager.setHotkeys` 绑定，与 Obsidian 系统快捷键互通
